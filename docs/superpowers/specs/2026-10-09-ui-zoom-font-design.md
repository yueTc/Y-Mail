## 1. 目标

- 用户能在「设置 - 外观」里把整个软件界面放大或缩小（页面缩放），范围 80%–150%。
- 用户能单独调界面文字大小（字体大小），用数字表示，档位 13 / 15 / 17 / 19 像素。
- 用户能改界面字体样式（字体样式）：系统默认 / 微软雅黑 / 等线 / 宋体 / 黑体 / 楷体。
- 三个偏好只影响本机显示，重启后还在，不碰邮件数据。

## 2. 非目标

- 不改邮件正文的排版内容，不改发信内容。
- 不新增网络请求，不写数据库，不碰凭据。

## 3. 设计

### 3.1 页面缩放（整个界面）

- 走 WebView 的原生缩放（`WebviewWindow::set_zoom`），等于浏览器「Ctrl + 加号」那种整体缩放：列表、设置、正文、按钮一起放大缩小，布局随之重排。
- 档位：80% / 90% / 100% / 110% / 125% / 150%，默认 100%。
- 快捷键：`Ctrl + 加号` 放大一档、`Ctrl + 减号` 缩小一档、`Ctrl + 0` 回到 100%。
- 缩放比例存本地 `localStorage`，键 `ymail.ui-zoom.v1`；启动时重新应用（原生缩放不跨进程保留）。
- 只作用于主窗口，不影响截图叠加窗。

### 3.2 字体大小（界面基准字号）

- 改根节点（`<html>`）的基准字号，界面里用 `rem` 的文字跟着变。
- 档位用数字表示：13 / 15 / 17 / 19 像素（界面显示形如 `15 px`），默认 15。
- 读信正文在独立 `iframe` 里，不继承根字号，读信组件把同一个字号带进去。
- 字号存本地 `localStorage`，键 `ymail.ui-font.v1`；启动时先应用，首帧就对。

### 3.3 字体样式（字体系列）

- 改根节点（`<html>`）的字体栈，界面文字跟着换字体。
- 档位：系统默认 / 微软雅黑 / 等线 / 宋体 / 黑体 / 楷体，默认系统默认（跟原来 `index.css` 的字体一致）。
- 每个档位对应一条固定字体栈（带英文名兜底），只认白名单，别的值一律当没设置过。
- 读信正文同样由读信组件把字体栈带进去。
- 选择存本地 `localStorage`，键 `ymail.ui-font-family.v1`；启动时先应用，首帧就对。

### 3.4 界面

- 「设置 - 外观」里在「深色模式」「界面语言」下面加三行：「页面缩放」「字体大小」「字体样式」三个下拉。

## 4. 验收标准

- R1（MUST）外观页出现「页面缩放」「字体大小」「字体样式」三个下拉，默认 100% / 15 px / 系统默认。
- R2（MUST）改页面缩放后整个界面一起变，重启后保持。
- R3（MUST）`Ctrl + 加号 / 减号 / 0` 能放大 / 缩小 / 复位，且外观页显示同步。
- R4（MUST）「字体大小」用数字表示（如 `15 px`），不再用小 / 标准 / 大 / 特大。
- R5（MUST）改字体大小或字体样式后界面文字跟着变，读信正文也跟着变。
- R6（MUST）三个偏好只存本地，不发网络、不写库。
- R7（MUST）四关（fmt / clippy / test / build）加 `npm test` 全绿。

## 5. 安全与合规

- 不新增网络、不写库、不碰凭据。
- 缩放数值后端再夹一次范围，防止越界值；字体样式只认白名单。
- 邮件正文仍是不可信内容，本规格不因正文触发任何行为。
