# 导航、账户入口与设备名调整设计规格

| 项 | 值 |
|---|---|
| 日期 | 2026-10-15 |
| 状态 | 用户已确认设计，规格已自检，待用户复核 |
| 范围 | 左侧主导航、设置分类、设置同步设备名 |

## 1. 背景

当前最左侧主导航同时显示图标和“收件箱 / 通讯录 / 设置”文字。设置页的“账号与同步”把邮箱账号管理和设置同步放在同一个分类中，进入路径不够清楚。设置同步创建新设备或加入已有同步时，设备名需要用户手动填写，默认值没有利用电脑本身的名称。

## 2. 目标

1. 最左侧主导航只显示收件箱、通讯录、设置三个图标，保留无障碍名称和鼠标悬停提示。
2. 设置入口固定在主导航底部，收件箱和通讯录保持在上方。
3. 将设置页的“账号与同步”拆成“账户”和“设置同步”两个独立分类。
4. 设置同步的设备名默认读取当前电脑名称，并允许用户在提交前修改。
5. 保持现有邮箱账号数据、设置同步数据、密码存储方式和外发安全门槛不变。

## 3. 非目标

- 不改变收件箱、通讯录或设置页内部已有功能。
- 不改变设置同步的远端存储、加密、密码校验、冲突处理和同步协议。
- 不新增设备名的独立持久化字段；设备名继续由设置同步记录保存。
- 不把密码、令牌或设备名写入日志。

## 4. 界面设计

### 4.1 最左侧主导航

主导航继续保留三个入口：

- 收件箱：图标按钮，位于顶部。
- 通讯录：图标按钮，位于收件箱下方。
- 设置：图标按钮，固定在导航栏底部。

三个按钮均隐藏可见文字，但保留 `aria-label` 和 `title`，保证键盘与辅助工具仍能识别入口，鼠标悬停时可以看到入口名称。选中态和现有图标保持不变。

### 4.2 设置分类

设置页分类调整为：

- 通用
- 外观
- 账户
- 设置同步
- 代理
- AI功能
- MCP
- 存储
- 通讯录
- 关于

“账户”只显示邮箱账号管理面板；“设置同步”只显示现有设置同步面板。两类面板在切换时继续保留挂载状态，避免未提交表单被销毁。

### 4.3 设备名输入

设置同步面板在加载时读取本机电脑名称，并将它作为以下两个输入框的初始值：

- 开启设置同步时的设备名。
- 加入已有设置同步时的新设备名。

输入框仍可编辑。用户清空后点击提交时，继续显示现有“请填写这台设备的名字”提示；用户修改后的名称按现有流程提交和保存。已开启同步的当前设备名继续从同步状态显示，不被本次默认值覆盖。

## 5. 数据与接口设计

### 5.1 读取电脑名称

在 Tauri 后端新增一个只读命令，用于返回当前操作系统提供的电脑名称。Windows 优先读取 `COMPUTERNAME`；没有可用值时再读取通用主机名环境变量；仍然读不到时返回“本机”。返回值只用于填写界面输入框，不包含密码或令牌。

前端在 `api.ts` 中增加对应调用封装。设置同步面板首次加载时调用该接口；读取失败时使用“本机”作为界面默认值，不阻塞设置页使用。

### 5.2 设置同步提交

开启同步和加入已有同步仍调用现有接口，并继续传入用户最终确认的设备名。后端现有的设备名清洗、长度限制和同步记录写入逻辑保持不变。

### 5.3 主导航类型

主导航仍使用现有三种工作区模式，不新增路由或数据状态。只调整导航按钮的布局和可见文字。

## 6. 兼容与错误处理

- 旧版本已经保存的同步设备名照常显示，不自动覆盖。
- 电脑名获取失败时默认使用“本机”，用户可以继续修改。
- 电脑名包含首尾空白时由界面提交前去除；后端继续执行现有清洗规则。
- 设置分类拆分只改变入口位置，不迁移或重写现有设置数据。

## 7. 验证标准

完成后需要满足：

1. 主导航可看到三个图标，文字不占位；设置图标位于底部；三个入口仍能正确切换工作区。
2. 设置页能分别打开“账户”和“设置同步”；邮箱账号面板和同步面板内容不串位。
3. 新打开设置同步面板时，开启同步和加入同步的设备名输入框默认显示电脑名称。
4. 修改设备名后提交，传给后端的是修改后的值；清空后仍有明确错误提示。
5. 电脑名接口失败时界面仍可用，并显示“本机”默认值。
6. 通过项目规定的四项检查：`cargo fmt --all --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace`、`npm run build`。

## 9. 方案取舍

采用“后端提供电脑名称、前端负责展示和编辑”的方案。电脑名属于操作系统信息，由后端读取更稳定，也不会让前端依赖额外的系统插件；输入框仍由前端控制，用户可以在提交前改成更容易识别的名称。主导航和设置分类只做现有状态的重新排布，改动小，兼容性好。
