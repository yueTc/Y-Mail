# 收件箱侧栏视觉刷新设计规格

| 项 | 值 |
|---|---|
| 日期 | 2026-10-17 |
| 状态 | 已实现；2026-10-17 追加：账号行改用统一入口的样式；用户澄清「粗」指按钮框太高，回调误改的字体和图标并压小按钮高度 |
| 范围 | 收件箱邮箱栏顶部、统一入口、写邮件入口、图标、计数胶囊、选中态 |
| 依据 | 用户 2026-10-17 提供的参考图；`docs/superpowers/specs/2026-10-05-inbox-ui-optimization-design.md` v1.4 |

## 1. 背景

当前邮箱栏的顶部入口只有文字，数量胶囊统一使用强调色；“写邮件”按钮位于中间邮件列表工具栏。用户提供的参考图要求：

- 写邮件按钮放在邮箱栏顶部，占满栏宽。
- 收件箱、未读邮件、红旗邮件、草稿箱、已发送、垃圾邮件、已删除各有图标。
- 未选中项目的数量胶囊使用浅灰底和灰色文字。
- 选中项目整行使用主题色浅底，图标、文字和数量胶囊一起跟随主题色。
- 蓝色只是参考图示例，实际颜色必须继续跟随用户当前选择的主题色。

## 2. 目标

1. 收件箱模式下的邮箱栏顶部先显示“写邮件”按钮，再显示统一入口。
2. 统一入口按参考图顺序显示：收件箱、未读邮件、红旗邮件、草稿箱、已发送、垃圾邮件、已删除。
3. 每个统一入口有独立图标、中文标签和可选数量胶囊。
4. 新增“垃圾邮件”和“已删除”的统一入口，按文件夹类型跨账号查看。
5. 视觉规则与参考图一致：普通行无底色，选中行有主题色浅底，普通胶囊为灰色，选中胶囊为主题色浅底。
6. 账号、文件夹树、右键菜单、“添加邮箱”等现有功能保留在统一入口下方。
7. 所有交互继续支持键盘焦点，颜色继续使用现有主题令牌。

## 3. 非目标

- 不修改邮件同步、文件夹管理、邮件删除或账号管理逻辑。
- 不修改服务端接口、数据库结构和数据迁移。
- 不删除账号、文件夹或“添加邮箱”入口。
- 不给数量胶囊写死蓝色；参考图中的蓝色只用于说明视觉效果。
- 不改变邮件列表、读信窗格、搜索、写信和附件逻辑。

## 4. 界面设计

### 4.1 写邮件按钮

- 位置：邮箱栏第一个元素，位于所有统一入口之前。
- 宽度：占满邮箱栏可用宽度；最小高度从 46 像素压到 34 像素，上下内边距各 2 像素；大字号时允许随内容撑高，避免文字被裁切。
- 外观：主题色实底、主题色前景色文字、圆角 8 像素；“写邮件”三个字单独相对于按钮水平、垂直居中，图标放在文字左侧、间距 8 像素。文字左右保留等宽空间，图标放在左侧空间末端，避免把文字挤偏。
- 文字：用户 2026-10-17 明确「粗」指按钮框而非文字，撤回此前误做的细体调整，恢复继承界面字体、字重 600 和原字号，不再单独指定细体。
- 图标：恢复原来的笔和纸张轮廓图标，描边 1.8，与统一入口图标一致。
- 点击行为：沿用现有新建写信请求，不做功能改动。
- 中间工具栏不再重复显示“写邮件”，避免同一动作出现两个常驻按钮。

### 4.2 统一入口

顺序固定为：

1. 收件箱
2. 未读邮件
3. 红旗邮件
4. 草稿箱
5. 已发送
6. 垃圾邮件
7. 已删除

每个入口一行，左侧图标，中间标签，右侧数量胶囊。图标含义如下：

- 收件箱：打开的收件托盘。
- 未读邮件：打开的未读信封。
- 红旗邮件：旗帜；保留参考图里的红色小标记作为语义提示。
- 草稿箱：纸张和笔。
- 已发送：纸飞机。
- 垃圾邮件：带感叹号的盾牌。
- 已删除：垃圾桶。

图标只作为装饰，必须带 `aria-hidden="true"`；按钮本身继续使用可读中文名称。

### 4.3 数量规则

- 收件箱：显示所有账号未读总数。
- 未读邮件：显示所有账号未读总数。
- 红旗邮件：不显示数量胶囊。
- 草稿箱：显示所有账号草稿文件夹邮件总数。
- 已发送：显示所有账号已发送文件夹邮件总数。
- 垃圾邮件：显示所有账号垃圾邮件文件夹邮件总数。
- 已删除：显示所有账号已删除文件夹邮件总数。
- 数量为 0 时不显示胶囊。
- 数量使用等宽数字，避免切换视图时标签左右跳动。

### 4.4 选中态与普通态

普通态：

- 行背景透明。
- 图标和标签使用现有次要文字色，不使用主题色。
- 用户要求查看全部加粗效果：统一入口、账号名称及展开后的文件夹名称统一字重 700，数量胶囊里的数字同样使用 700；普通、悬停和选中状态保持同一字重。字号、行高、图标描边、缩进及配色沿用现值。
- 数量胶囊使用浅灰底和灰色文字。
- 鼠标悬停时只出现轻微中性底色或现有悬停底色，不描亮边框。

选中态：

- 整行使用主题色约 10% 的浅底色。
- 图标和标签使用主题色。
- 数量胶囊使用主题色约 16% 至 20% 的浅底色，文字使用主题色。
- 不增加亮色描边。
- 键盘焦点使用现有主题色焦点环。

主题色由 `accentColor.ts` 写入现有 `--accent`、`--accent-fg` 等变量；当前用户选择粉色时，按钮、选中行和选中胶囊都应显示粉色体系，而不是蓝色。

### 4.5 现有账号与文件夹区域

- 统一入口下方继续显示账号列表、账号文件夹树和“＋ 添加邮箱”。
- 账号行沿用统一入口的行样式：同样的行高、次要文字色和数量胶囊。
- 账号色标继续使用 3 像素竖条，放在与上方图标同宽的 20 像素列里居中，文字才和上面的入口对齐；不改成圆形。
- 账号的未读数量改用和统一入口一致的浅灰底胶囊，选中时跟随主题色；账号名称按本次加粗预览要求统一字重 700。
- 账号和文件夹的现有右键菜单、展开收起和计数刷新逻辑不变。
- 用户补充要求：账号展开后的文件夹也统一为上方入口的样式，同样的行高、字号、次要文字色、图标列和悬停效果；保留文件夹缩进与服务器原名。收件箱、红旗、草稿、已发送、垃圾邮件、已删除复用对应图标，自定义、归档等其他文件夹用通用文件夹图标。所有装饰图标带 aria-hidden="true"。
- 文件夹未读数量统一使用浅灰底灰字胶囊；选中时整行、文字、图标和胶囊跟随主题色，胶囊为浅色底，不再使用主题色实底白字。计数仍为各文件夹原有未读数，数量为零时不显示。

## 5. 数据与状态设计

`UnifiedView` 扩展为：

- `inbox`
- `unread`
- `flagged`
- `draft`
- `sent`
- `junk`
- `trash`

跨账号文件夹查询继续使用现有 `folderKind` 条件；`draft`、`sent`、`junk`、`trash` 都按文件夹类型查询，不新增后端接口。

顶部统一入口的计数继续来自现有 `inboxSummary()` 与 `listInboxFolders()`：

- `inbox`、`unread` 使用 `totalUnread`。
- `draft`、`sent`、`junk`、`trash` 使用 `folderKindMessageCount()` 合计 `messageCount`。
- `flagged` 不显示数量。

## 6. 文案与国际化

中文标签按参考图调整为：

- 未读邮件
- 红旗邮件
- 草稿箱
- 已发送
- 垃圾邮件
- 已删除

英文对照同步加入现有 `i18n.en.ts`，不让界面在英文模式出现中文残留。

## 7. 验证标准

1. 收件箱侧栏顶部第一项是主题色“写邮件”按钮，中间工具栏没有重复按钮；按钮最小高度为 34 像素、上下留白压小，文字和图标恢复误改前样式；“写邮件”文字本身位于按钮正中，左侧图标不能使文字偏右；用实际渲染高度和截图确认，13 至 19 像素字号下文字、图标不能裁切。
2. 七个统一入口顺序正确，均有对应图标；统一入口、账号和文件夹名称及数量数字均使用 700 字重，选中切换时不改变字重。
3. 未选中行的图标和文字为普通灰黑色，数量胶囊为浅灰底。
4. 选中行整行出现主题色浅底，图标、文字和数量胶囊跟随主题色。
5. 当前主题色为粉色时，按钮、选中行和选中胶囊显示粉色；切换主题色后同步变化。
6. 草稿箱、已发送、垃圾邮件、已删除能跨账号打开对应文件夹内容。
7. 账号行和展开后的文件夹行的行高、文字色、普通及选中数量胶囊与上方统一入口一致；文件夹有对应图标，保留缩进、原名和未读计数；账号色标仍是竖条并对齐上方图标列；文件夹树、右键菜单和“添加邮箱”仍可用。
8. 保持通过项目规定的四项检查：`cargo fmt --all --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace`、`npm run build`。

## 9. 方案取舍

采用“沿用现有四栏结构，只刷新邮箱栏统一区”的方案。优点是改动集中、账号和文件夹功能完全保留、主题色自然继承现有令牌。相比新做一整套侧栏，这个方案风险更低，也能直接达到参考图的核心效果。
