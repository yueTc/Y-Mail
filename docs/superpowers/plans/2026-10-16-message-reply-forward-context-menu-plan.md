# 邮件回复、转发右键菜单与会话聚合图标实施计划

## 1. 修改收件箱工具栏与邮件右键菜单

文件：`src/InboxPanel.tsx`

- 从顶部 `inbox-toolbar` 删除“回复”和“转发”两个按钮。
- 把“按会话聚合”复选框替换为图标按钮。
- 增加关闭、开启两种线程列表内联 SVG，按钮使用 `aria-label`、`title` 和当前状态属性；红旗视图下继续禁用。
- 在邮件右键菜单顶部加入“回复”和“转发”菜单项。
- 菜单项使用 `messageMenu.message.id` 设置现有 `ComposeRequest`，并关闭菜单。
- 保持分类、手动分类、删除和现有菜单关闭逻辑不变。
- 将“只看未读”复选框替换为两态信封图标按钮；统一入口“所有未读”下保持禁用。
