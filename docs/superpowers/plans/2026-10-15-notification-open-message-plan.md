# 点击通知打开邮件实施计划

依据：主规格 R11 与同日 notification-open-message-design.md。用户已确认点击时将窗口带到最前面，随后正常切换其他软件。

1. 为两类 Windows 通知共用响应处理入口，默认点击打开本地邮件；保留经过校验的按钮动作，忽略关闭事件。
2. 在窗口主线程顺序执行显示、恢复最小化、聚焦，记录通用失败信息。
3. 邮件页点击通知时通知 App 切回收件箱；使用常驻监听与最新回调，防止筛选切换丢事件和旧请求覆盖新点击。
4. 读取目标邮件后直接显示；编号无效不读库，邮件不存在时给出提示；写信内容保持挂载，读信时可继续写信。
5. 新增后端响应分流测试、界面通知回归，先确认旧实现失败，再修改实现验证。
6. 运行四项必检和前端测试，检查差异；更新三份记忆。真实桌面通知和焦点未验证时据实记录。
