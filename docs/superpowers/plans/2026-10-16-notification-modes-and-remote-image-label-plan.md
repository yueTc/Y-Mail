# 通知触发时机与远程图片文案实施计划

依据：2026-10-16-notification-modes-and-remote-image-label-design.md，用户已复核确认。

1. 后端设置增加 `notifyNewMailWhen`，取值为 `unfocused`、`always`、`background`，缺字段默认 `unfocused`。
2. 设置同步同时保存该值；旧同步包缺字段时保持本机默认，不覆盖用户选择。
3. 通知循环按「开关 + 时机」判断是否弹系统通知：不聚焦看焦点，后台看窗口是否可见；状态读不到时按宁可多弹处理。
4. 设置页把两处文案改成指定文字，在通知总开关下增加三选一下拉；总开关关闭时下拉置灰但保留值。
5. 保存设置的所有入口都带上新字段，首次启动向导也不能覆盖已有选择。
6. 补后端设置、通知判定、同步读写和前端设置页测试，再跑四项必检。
