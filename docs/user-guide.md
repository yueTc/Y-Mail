# Y-Mail 用户手册（0.1.0）

本地优先的多邮箱统一收件箱客户端。邮件、附件和密钥都留在你自己电脑上；AI 与翻译默认关闭，每次外发都要你点头。

---

## 1. 安装

只支持 Windows 10 / 11（64 位）。安装包有两种，任选其一：

| 安装包 | 适合谁 | 说明 |
|---|---|---|
| `ymail_0.1.0_x64-setup.exe`（NSIS） | 大多数个人用户 | 默认装到当前用户目录，不需要管理员权限；安装时会自带 `ymail-mcp.exe` |
| `ymail_0.1.0_x64_en-US.msi`（MSI） | 需要统一部署的机器 | 走标准 Windows 安装程序，便于批量分发 |

安装前请确认：

- 系统已装 **WebView2 运行时**（Windows 10/11 一般自带；没有的话微软官网有免费安装包）。
- 有一份可用的邮箱账号，并已开启 IMAP / SMTP 服务（国内邮箱多半需要单独申请「授权码」，不是登录密码）。

安装完成后从开始菜单启动「统一收件箱」。

### 数据放在哪

| 内容 | 位置 |
|---|---|
| 数据库（含邮件、附件元数据） | `%APPDATA%\com.ymail.desktop\ymail.db` |
| 日志 | `%APPDATA%\com.ymail.desktop\logs\ymail.log.<日期>` |
| 下载的附件 | `%APPDATA%\com.ymail.desktop\downloads\` |
| 凭据（授权码 / OAuth 令牌 / AI 密钥） | Windows 凭据管理器（不是文件，谁也不许拷出来） |

日志只写本机，不上传任何地方。

## 2. 首次配置

打开应用后有顶栏两个页签：**收件箱** 和 **账号与代理**。首次使用按下面顺序做：

1. **加账号**：在「账号与代理」页签点「添加账号」。
   - 国内邮箱（QQ / 163 / 126 等）：选对应预设，填邮箱地址和「授权码」。
   - Gmail / Outlook：认证方式选「OAuth2（浏览器授权）」，见第 4 节。
   - 企业邮箱 / 自建邮箱：手动填 IMAP 与 SMTP 的服务器地址、端口和加密方式。
2. **先做连接自检**：点「连接自检」。系统会真的去连一次收件和发件服务器。
   - 通过才会保存；失败会给出「认证失败 / 网络不可达 / 加密失败」的区分提示，并且**不会**留下半个账号。
3. **开始同步**：保存后在「同步」面板点「同步全部」或「同步这个账号」。首次会先拉最近 30 天 / 500 封元数据，之后在空闲时按批补齐历史。
4. **需要代理的账号**：见第 3 节。
5. **想用 AI 或翻译**：默认是关闭的，见第 6 节。

> 授权码、令牌、AI 密钥只进 Windows 凭据管理器。数据库、日志、报错里都不会出现明文；界面上任何已保存的密钥都不会回显。

## 3. 账号与代理

### 3.1 代理策略

代理分三层，优先级从高到低：

1. **账号级**：只让某个账号走代理（Gmail 常需要）。
2. **全局自定义**：所有「跟随全局」的账号共用一个代理。
3. **跟随系统**：读 Windows 系统代理设置。
4. **直连**：不走代理。

> 如果系统代理用的是自动配置脚本（PAC），当前版本不支持，界面会提示你改用「自定义代理」或「直连」。

在「代理」面板里可以：

- 添加 SOCKS5（支持用户名 / 密码）或 HTTP CONNECT 代理。
- 点「测试连接」确认这条代理通不通。
- 修改或删除；删除后相关账号会自动回落到「跟随全局」。

### 3.2 失败时怎么办

- 单个账号连不上，不会影响其它账号。界面会标出「代理失败」并自动重试最多 2 次。
- 授权码错了会提示「登录被服务器拒绝」，重新编辑账号、重填授权码即可。
- Gmail / Outlook 授权过期时会提示「授权已失效」，重新点「开始授权」走一遍浏览器流程。

## 4. Gmail / Outlook 的 OAuth2 客户端编号怎么配

OAuth2 需要你自己在服务商后台注册一个「桌面应用」，拿到**客户端编号**（Client ID）。这样做是因为应用不内置任何公共密钥，也不代管你的账号权限。

1. **注册应用**
   - Gmail：Google Cloud Console → 新建项目 →「API 和服务」→「凭据」→ 创建 OAuth 客户端 ID → 应用类型选「桌面应用」。
   - Outlook：Microsoft Entra 管理中心 →「应用注册」→ 新注册 → 受支持的账户类型选「个人 Microsoft 账户」或你需要的类型 → 平台选「移动和桌面应用」。
2. **登记回环回调地址**：应用授权时用的是 `http://127.0.0.1:<随机端口>` 这种本机回环地址，所以要在服务商后台的回调地址里登记 `http://127.0.0.1` 这一类回环地址（Gmail 的桌面应用类型支持回环地址，端口可随机；Outlook 需要在应用里勾选「允许公共客户端流」并把回环地址加进重定向 URI）。
3. **在应用里填编号**：添加账号 → 认证方式选「OAuth2（浏览器授权）」→ 选服务商 → 粘贴客户端编号 → 点「开始授权」。
4. **在系统浏览器里登录并同意**，然后回到应用等它自动完成自检。
5. 之后有失效时，应用会自动用刷新令牌换新令牌；换不回来会提示你重新授权。

> 客户端编号本身不是密钥，会存在本机数据库里；**客户端密钥不用填，也不该填**——本项目走的是 PKCE 公共客户端流程。

## 5. 收件箱、读信与搜索

- **统一收件箱**：把所有账号的 inbox 按时间倒序合并显示，每条带账号色标；可以切成「会话」模式把同一线程折叠。
- **读信**：打开邮件时才去联网取正文；正文在沙箱里渲染。
  - 远程图片默认拦下，界面显示「已拦截远程图片（N）」，点「放行远程图片」只对当前这封生效。
  - 脚本、表单、事件属性都会被清掉。
  - 附件按需下载；`.exe` 等可执行文件会标红警示。
- **搜索**：支持关键词和几种语法：
  - `from:某人` 按发件人搜
  - `has:attachment` 只看带附件
  - `is:unread` 只看未读
  - `before:2026-01-01` 只看某个日期之前
  - 本地结果不够时会自动联网补一批历史（按需深拉），失败也不影响本地结果。

## 6. AI 与翻译

**默认全部关闭。** 没有配置站点时，翻译 / 摘要按钮显示「需启用」，不会产生任何外发请求。

### 6.1 添加站点与 CDKey

在「账号与代理」页签的「AI 与翻译」里：

1. 点「添加站点」，填名称、类型和地址：
   - **OpenAI 兼容站点**：第三方中转站或自建站点，填 `base_url`（例如 `https://api.example.com/v1`）。非本机地址必须是 HTTPS。
   - **本机 Ollama**：填 `http://127.0.0.1:11434`，可零外传。
   - **DeepL**：填 DeepL 的 API 地址。
2. 填 **CDKey / API Key**。它只进 Windows 凭据管理器，不会入库、不会进日志、保存后不回显。
3. 点「测试连接」，成功后可以「拉取模型」选一个默认模型。
4. 需要的话，给「翻译 / 摘要 / 润色 / 起草」分别指定模型和「思考程度」（关闭 / 低 / 中 / 高）。模型不支持时应用会自动降级并标注，不会让调用失败。

### 6.2 每次外发都要你点头

点翻译 / 摘要 / 润色时，会先弹一个确认框，写清三件事：

- **外发到哪个域名**
- **用哪个模型**
- **是不是本地**（本地就是零外传）

确认之后才会真的调用。每次调用只用一次授权，内容变了就得重新确认。

### 6.3 翻译三种模式

先翻一次拿到「段落对齐译文」，然后随便切：

| 模式 | 效果 |
|---|---|
| 对照翻译 | 左原文、右译文并排 |
| 行内翻译 | 每个原文段落下面插入对应译文 |
| 直接翻译 | 正文整体替换成译文，可一键切回原文 |

**切换模式不会再调一次模型**，因为三种模式共用同一份译文（本地也缓存了）。

### 6.4 一键关闭

设置里有「一键关闭 AI」（停用全部站点并作废已发出的授权）和「清空 AI 缓存」。

> 安全提醒：邮件正文是**不可信内容**。模型输出只按纯文本显示，不会触发发送、跳转、写库等任何动作。

## 7. 把 MCP 接给外部 Agent

MCP 是让外部 Agent（Codex / Claude Desktop / Cursor 等）只读地查你本机邮件的一种本地协议。它**默认关闭**，只走标准输入输出，**不监听任何网络端口**。

1. 在「账号与代理」页签找到「MCP 外部接入」，先点「启用 MCP」。
2. 界面会生成一段配置示例，`command` 指向安装目录里的 `ymail-mcp.exe`，`env.YMAIL_DATA_DIR` 指向应用数据目录。把这段填进对应 Agent 的配置文件。
   - 典型安装位置：当前用户安装是 `%LOCALAPPDATA%\Y-Mail`，机器级安装是 `C:\Program Files\Y-Mail`。以界面给出的实际路径为准。
3. 只读工具（一直可用）：`list_accounts`、`list_folders`、`search_messages`、`get_message`、`get_thread`。
4. 写工具（`create_draft`，只能建草稿，绝不发送）默认关闭，需要单独点「打开写工具」。**发送类工具不存在**，直接调用会被拒绝。
5. 每次调用都会在本机 `mcp_audit` 表留一条审计（工具名、账号范围、参数哈希、状态），**不含正文与凭据**。
6. 不想用了就点「关闭 MCP」，立即生效，已连上的会话也会被拒。

## 8. 托盘、通知与深色模式

- 关闭主窗口后应用驻留托盘；有新邮件会弹系统通知。
- 界面支持深色模式，选择会记在本机。
- 想彻底退出，用托盘菜单里的退出。

## 9. 故障排查

| 现象 | 先查什么 | 怎么处理 |
|---|---|---|
| 提示找不到 IMAP / SMTP 服务器 | 地址、端口、加密方式是否正确 | 对照邮箱服务商官方说明重填；企业邮箱找管理员要参数 |
| 提示认证失败 | 用错密码了吗 | 国内邮箱要用「授权码」，不是登录密码；到邮箱网页版重新生成 |
| 提示 STARTTLS 失败 | 端口和加密方式对不上 | 常见组合：IMAP 993（SSL/TLS）、SMTP 465（SSL/TLS）或 587（STARTTLS） |
| Gmail 连不上 | 本机能否直连 Google | 给这个账号单独配一个代理（见 3.1） |
| OAuth2 授权失败 | 客户端编号与回调地址 | 检查服务商后台的回环地址登记；确认应用类型是桌面 / 公共客户端 |
| 同步卡住或没新邮件 | 同步面板的状态 | 点「同步这个账号」重试；看日志里的错误码 |
| 搜索搜不到老邮件 | 历史还没补齐 | 等后台补齐，或直接搜（会触发按需深拉） |
| 想彻底重来 | — | 退出应用，备份后删除 `%APPDATA%\com.ymail.desktop\ymail.db*`；凭据要在 Windows 凭据管理器里手工删（名称前缀 `com.ymail.desktop`） |
| AI 调用报错 | 站点地址 / 密钥 / 模型 | 在设置里点「测试连接」和「拉取模型」；非本机站点必须 HTTPS |

日志在 `%APPDATA%\com.ymail.desktop\logs\`，只在本机，不会上传。

## 10. 隐私说明

- **密钥不出本机**：授权码、OAuth 令牌、代理密码、AI 密钥都只进 Windows 凭据管理器；数据库、日志、报错里没有明文。
- **邮件不出本机**：同步、搜索、读信、附件都在本机完成；应用本身不向任何服务器上报数据，也没有遥测。
- **远程图片默认拦**：HTML 邮件里的远程图片默认不发请求，要你单封放行才加载。
- **AI / 翻译默认关闭**：不配置、不确认，就不会有任何正文外发；每次外发都写清目标域名、模型、是否本地。
- **本地审计**：AI 调用与 MCP 调用都在本地留审计，只记元数据，不记正文原文。
- **可一键关闭**：AI 与 MCP 都有总开关，关了立即生效。
